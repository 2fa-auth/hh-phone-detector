# Resumetto Phone MVP

Небольшой standalone-сервис для поиска телефонов, опубликованных непосредственно
в вакансиях.

## Что делает

1/ Принимает нормализованные вакансии.
2/  Сначала проверяет структурированные `contacts`.
3/ Затем ищет кандидатов в `description`.
4/ Валидирует кандидатов библиотекой `phonenumbers`.
5/ Нормализует номер в E.164.
6/ Удаляет дубликаты.
7/ Возвращает результаты по вакансиям с телефонами.

Номер никогда не ищется во внешнем интернете и не генерируется.

## Стек
 => Python 3.11+
 => Pydantic
 => phonenumbers
 => httpx
 => pytest
